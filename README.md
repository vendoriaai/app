# Vendoria — the AI answer engine that shows its work

Vendoria answers questions with numbered citations, then checks every claim against the page it came from — supported, partial, or unverified, you see which before you rely on the answer.

- **Web app**: https://vendoria.am (no account needed to try it)
- **Downloads**: see the [Releases](https://github.com/vendoriaai/app/releases) — Windows installer + Android APK + a 27-second demo video

## Install notes

- **Windows** (unsigned build): SmartScreen may show \"Windows protected your PC\" — choose *More info* → *Run anyway*.
- **Android** (debug-signed APK): sideload with \"Install unknown apps\" enabled for your browser/file manager.

Vendoria is closed source. This repository exists only to distribute the app binaries.
